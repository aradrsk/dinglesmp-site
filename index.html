How to join

Takes about 30 seconds.

☕ Java Edition

  1. Open Minecraft and click Multiplayer
  2. Click Add Server
  3. Server address: play.dingleberrysmp.com
  4. Accept the resource pack (it adds the rank badges)
  5. Type /rtp to head into the wild

📱 Bedrock Edition

  1. Go to Play → Servers → Add Server
  2. Address: play.dingleberrysmp.com
  3. Port: 19132
  4. Works on phone, Xbox, PlayStation, Switch and Windows

FAQ

Is it really free?

Yes. There's no store, no paid ranks and no paid keys. Everything is earned by playing.

What version is the server?

26.2. Older Java versions can usually join too, and Bedrock players are supported.

Is griefing allowed?

No. Claim your land and only the people you trust can build or open chests there.

Is PvP on?

Yes, in the survival world. Spawn is a safe zone. If you log out while in combat, you die.

How do I report a cheater?

Use /report <player> <reason> in game. We also run an anticheat.

Can I get a media rank?

If you make YouTube or TikTok videos on the server, ask in our Discord. It's free too.
